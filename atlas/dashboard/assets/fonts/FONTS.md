# 대시보드 글꼴

| 파일 | 원본 | 라이선스 |
|---|---|---|
| `NotoSansKR-VF.ttf` | Noto Sans KR 가변 글꼴(Google) — 라틴·기호·한글 음절 전체만 남김 | SIL Open Font License 1.1 |
| `NotoSerifKR-VF.ttf` | Noto Serif KR 가변 글꼴(Google) — 라틴·기호·대시보드 문구에 쓰인 한글만 남김 | SIL Open Font License 1.1 |

- 줄인 방법: `tool/subset_fonts.py`(fontTools). 굵기 축(wght)과 글꼴 안의 이름 표(저작권·라이선스 정보)는 그대로 둔다.
- 라이선스 전문: https://openfontlicense.org (글꼴 파일의 name 표 13·14번에도 들어 있다)
- 글꼴 이름은 원본 그대로 쓰고, 줄인 파일을 따로 팔지 않는다(OFL 조건).
